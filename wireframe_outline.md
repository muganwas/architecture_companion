🖼️ Wireframe Outline
1. Landing Page

Header: “AI Architecture Companion”

CTA Buttons: “Describe in Text” / “Upload Sketch”

Preview: Example floor plan thumbnail (to spark curiosity)

Footer: About + Tech credits

2. Input Screen (Text or Sketch)

Option A: Text box → “Describe your building idea”

Option B: Upload area → drag‑and‑drop sketch (PNG/JPG/PDF)

Button: “Generate Layout”

3. Processing Screen

Animated progress bar with text like:
“Parsing requirements…”  
“Analyzing sketch geometry…”  
“Generating floor plan…”

4. Results Screen (Core Output)

Main Canvas:

Auto‑generated 2D floor plan (vector placeholders).

Toggle to switch to 3D view.

Sidebar:

Room list with dimensions.

Sustainability score (light/ventilation/energy).

Cost estimate (basic tier).

5. Interaction Options

Hover: See which text/sketch element inspired each layout piece.

Style Switcher: Dropdown (modern, rustic, minimalist).

Regenerate Button: “Try a new variation.”

6. Export Screen

Options:

Download 2D/3D plan (PNG/SVG).

Export to CAD/BIM format.

Share link with collaborators.
